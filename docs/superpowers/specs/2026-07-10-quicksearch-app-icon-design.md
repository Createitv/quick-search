# QuickSearch App Icon Design

## 目标

为 QuickSearch Windows 桌面应用创建一枚浅色、现代、具有科技感的应用图标。图标需要直接表达“快速搜索并打开文件夹”，并在窗口标题栏、任务栏、托盘和安装包等小尺寸场景中保持可辨识。

## 视觉方案

采用已确认的方案 A：浅蓝渐变文件夹作为主体，右前方叠加半透明放大镜，并加入一道简洁的速度光轨。

- 配色：冰青、浅蓝、少量白色高光。
- 风格：现代圆角、轻微玻璃质感、简洁科技感。
- 构图：主体居中，四周保留安全边距，适合正方形图标画布。
- 背景：透明。
- 禁止：文字、字母、品牌标识、真实场景、复杂纹理、投影地面和水印。

## 小尺寸约束

- 文件夹轮廓和放大镜圆环必须具有明确的明暗边界。
- 速度光轨只保留一到两道，避免缩小后形成噪点。
- 16×16 和 24×24 下优先保留文件夹与放大镜，玻璃高光可以弱化。
- 图标不得依赖细小文字或内部装饰表达含义。

## 资产与接入

1. 使用内置 ImageGen 生成高分辨率正方形 PNG 源图。
2. 使用纯色键控背景生成并在本地移除背景，验证透明角落和边缘无明显色边。
3. 保存项目源图为 `src/QuickSearch.Windows/Assets/QuickSearch-icon.png`。
4. 生成包含 16、20、24、32、40、48、64、128、256 像素层级的 `src/QuickSearch.Windows/Assets/QuickSearch.ico`。
5. 将 ICO 配置为 WPF 程序的 `ApplicationIcon`，同时设置主窗口与设置窗口图标。
6. 托盘 `NotifyIcon` 使用同一 ICO，不再使用系统默认应用图标。
7. Inno Setup 使用同一 ICO 作为安装程序和卸载程序显示图标。

## 验证标准

- PNG 确认含 Alpha 通道，四角透明，无明显键控色残留。
- ICO 确认包含规定的多尺寸图层。
- Windows WPF Release 构建无警告、无错误。
- 自包含 `win-x64` 发布产物包含图标资源，EXE 具备应用图标。
- GitHub Actions 安装包构建继续通过。

## 范围外

本次不修改应用名称、界面配色、布局、功能逻辑或品牌文案，也不创建额外 Logo 字体系统。
